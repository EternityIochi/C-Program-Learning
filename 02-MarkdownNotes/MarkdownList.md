# Markdown列表
Markdown支持**有序列表**和**无序列表**。  

***  

## 无序列表  
无序列表使用星号(-)，加号(+)或是减号(-)作为列表标记，这些标记后面要添加一个空格，然后再填写内容：  
<mark>~~Example:~~</mark>
* 第一项  
* 第二项  
* 第三项  

+ 第一项  
+ 第二项  
+ 第三项  

- 第一项  
- 第二项  
- 第三项  

### 选择建议：  
- 建议统一用减号`-`,因为他在视觉上更清晰  
- 在同一文档中保持一致的标记方式  
- 标记符号后必须有一个空格  

----------------

## 有序列表  
有序列表用于展示有顺序要求的步骤或项目。  
有序列表使用数字加上`.`号来表示，<mark>~~如:~~</mark>  
1. 第一项  
2. 第二项  
3. 第三项  

### 数字可以不连续  
Markdown会自动修正数字顺序:  
    1. 第一项  
    5. 第二项(显示2)  
    7. 第三项(显示3)  

1. 第一项  
5. 第二项(显示2)  
7. 第三项(显示3)  

从指定数字开始:  
    5.第五项
    6.第六项  
    7.第七项  

5.第五项  
6.第六项  
7.第七项  

-----------------  

## 列表嵌套  
### 列表嵌套技巧  
列表可以嵌套使用，创建多层次的结构  
- 水果
 - 苹果
    - 红苹果
        - 绿苹果
    - 香蕉
    - 橙子
- 蔬菜  
    - 胡罗卜  
    - 白菜  
### 有序列表嵌套:  
1. 准备阶段  
    1. 收集资料
    2. 制定计划
2. 执行阶段
    1. 开始实施
    2. 监控进度
3. 总结阶段  
### 混合嵌套 
1. 主要任务
    - 子任务A
    - 子任务B
        1. 详细步骤1
        2. 详细步骤2
    - 子任务C 
2. 次要任务  
列表混合嵌套只需要在子列表的选项前面添加两个或者四个空格即可:  
1. 第一项:
    - 第一项嵌套的第一个元素  
    - 第一项嵌套的第二个元素  
2. 第二项: 
    - 第二项嵌套的第一个元素
    - 第二项嵌套的第二个元素  
### 嵌套规则:  
- 子列表需要缩进2-4个空格(推荐2个)
- 保持一致的缩进长度  
- 可以无限层嵌套，但实际使用中建议不超过3层

## 任务列表(复选框列表)  
任务列表是Github风格Markdown的扩展功能,现在被广泛支持:
### 基本语法:  
- [ ] 未完成的任务
- [X] 已完成的任务
- [ ] 另一个未完成的任务

#### 实际应用实例:  
## 项目待办清单

### 设计阶段
- [x] 需求分析
- [x] 原型设计
- [ ] UI 设计

### 开发阶段
- [ ] 前端开发
  - [x] 页面布局
  - [ ] 交互功能
  - [ ] 响应式适配
- [ ] 后端开发
  - [ ] 数据库设计
  - [ ] API 开发
  - [ ] 性能优化

### 测试阶段
- [ ] 单元测试
- [ ] 集成测试
- [ ] 用户验收测试
